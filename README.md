# 课程表助手

把教务系统导出的 **PDF 课程表**变成可以直接导入 **Apple 日历（macOS「日历」App）** 的文件。

只有一个网页文件：**`课程表助手.html`**。双击它就能用，不需要安装、不需要联网、不需要装任何软件。

---

## 怎么用

### 1. 双击 `课程表助手.html`

用浏览器打开（Safari / Chrome / Edge 都行）。网页里已经内置了 `课表.pdf` 这份示例，
打开后会立刻自动识别出来给你看，不用做任何额外操作。

> 如果浏览器问「是否允许」，直接允许即可；所有解析都在你自己电脑的浏览器里完成，
> 文件不会上传到任何地方，也不需要联网。

### 2. 换成你自己的课表

把新的 PDF **直接拖到网页窗口里**，或者点右上角「打开 PDF 课程表」选文件。
（内置的示例只是方便你先看效果，随时可以替换。）

### 3. 核对第 2 步的「学期设置与每节课的时间」

- **第 1 周周一的日期**：所有课程的日期都从这一天往后推算。程序会根据 PDF 里的
  「2026-2027学年第1学期」自动猜一个，**请务必核对**，不对就改。选定非周一的日期时会自动
  帮你挪到那一周的周一。
- **每节课的时间**：默认给了一套常见的作息，按你们学校的实际上课时间改。
  第 1 节是上午第一节课，以此类推；可以增删节次。懒得一节节填就用下面的自动排课。

#### 课间时间 · 自动安排上课时间

点开「每节课的时间」下面的这个折叠面板：

1. 填 **每节课时长**（比如 45 分钟）和 **课间休息**（比如 10 分钟）；
2. 需要的话填 **大课间**：每个时段的 **第几节之后** 插一段更长的休息
   （填 `2` 就是上午、下午各自在第 2 节之后空出大课间；填 `0` 表示不要大课间）；
3. 给 **上午 / 下午 / 晚上** 分别填这一时段第一节课的 **开始时间** 和 **节数**
   （节数填 `0` 表示这个时段没课）；
4. 点 **「一键排好上课时间」**，上面每一节的上下课时间就全填好了，之后还能手动微调。

分成上午 / 下午 / 晚上三段，是为了让 **午休、晚饭这种长间隔** 也能按你填的开始时间正确排进去
（如果只按一个课间一路往后推，午饭时间就不对了）。**大课间在每一段里各算各的**，
所以上午、下午的中间都会空出来；时段的最后一节之后不会插大课间。

每行右侧会实时显示这个时段的起止和它的大课间（例如
「第 1–4 节 · 08:00–11:40（09:40–10:00 大课间）」），按钮旁边显示总节数和最后一节的下课时间。

举个例子：每节 45 分钟、课间 10 分钟、大课间 20 分钟放在第 2 节之后，
上午 08:00 排 4 节、下午 14:00 排 4 节、晚上 19:00 排 2 节，得到的就是

```
第1节 08:00-08:45   第2节 08:55-09:40   第3节 10:00-10:45   第4节 10:55-11:40
                    └── 09:40-10:00 大课间 ──┘
第5节 14:00-14:45   第6节 14:55-15:40   第7节 16:00-16:45   第8节 16:55-17:40
                    └── 15:40-16:00 大课间 ──┘
第9节 19:00-19:45   第10节 19:55-20:40
```

（第 3 节和第 7 节比普通课间晚 10 分钟开始，就是那 20 分钟大课间让出来的。）

自动排课的设置会和其它设置一起记在浏览器里，下次打开还在，也能通过「保存设置 / 读取设置」带走。
点「恢复默认作息」会把作息表和这套自动排课参数一起还原成默认值。

### 4. 核对并修改课程

第 3 步的表格里，每一行都是一门课，所有格子都能直接改：

| 列 | 说明 |
| --- | --- |
| ☑ | 取消勾选 = 这门课不导出，那一行会立刻变灰（取消「全选」后再单独勾回来，灰色也会立刻消失） |
| 课程名称 | 从 PDF 里识别出来的课程名 |
| 星期 | 星期几上课 |
| 节次 | 第几节到第几节，两个下拉框分别是起始节和结束节 |
| 周次 | 例如 `1-16`、`1-16(单)`、`2,4,6,8`、`3-11`；点「选择」可以用鼠标点选。输入框后面会用浅色小字标出**这门课不上的周**，比如 `不上：11-18`、`不上：2-18(双)`。周次是连着的（每周都上）就不显示，干干净净 |
| 任课教师 / 上课教室 | 会写进日历事件的备注和地点 |
| 原文 | 点一下能看到 PDF 里这门课的原始文字，方便对照 |

右上角可以切换「周课表预览」，用整学期的课表样子快速检查星期和节次有没有错。
漏掉课程可以点「＋ 手动添加一门课」。

### 5. 确认后生成日历文件

滑到最下面，点 **「生成并下载 .ics 文件」**，会先弹一个确认框把关键信息列一遍，
确认无误后点「确认生成 .ics」。

下载得到的 `.ics` 文件 **双击就会用「日历」App 打开**，选择要放进哪个日历，
点「添加」即可。之后手机上（同一个 iCloud 账号）也会同步看到。

> 如果双击 `.ics` 没反应，展开页面底部的「预览 / 手动复制 .ics 内容」，
> 把内容复制到「文本编辑」里存成 `课程表.ics`（格式选「纯文本」），再双击打开。

## 支持哪些课程表 PDF

已经验证过的版式：

- **表格版（横版）**：左边一列节次、上面一列星期，格子里是课程 —— 例如
  `专业基础实训★(1-6节)10周,19周/场地:8-303/教师:黎志芬/教学班:...`
- **表格版（竖版）**：格子里写作 `高等数学A` + `[1-2节]1-16周(单)` + `教室: 教三-201` + `教师: 王小明`
- **清单版（没有表格）**：一门课一段，写作 `上课时间：星期一 第1-2节` / `上课周次：1-16周` /
  `上课地点：教二-305` / `任课教师：刘伟`

能识别的写法包括：

- 星期：`星期一` `周一` `礼拜一` `Monday`
- 节次：`(1-2节)` `[1-2节]` `【1-2节】` `第1-2节` `1-2节`
- 周次：`1-16周` `第2周` `10周,19周` `1-16周(单)` `2-16周(双)` `1-16周(除8周)`
- 教师/教室：`教师:` `老师:` `任课教师:` `场地:` `教室:` `上课地点:` `地点:`（顺序随意）
- 自动还原 PDF 里的兼容字符（如 `⾼` → `高`、`⼀` → `一`、`⻩` → `黄`），
  这类字符常见于用浏览器「打印成 PDF」生成的文件

**不支持**：扫描件 / 图片版 PDF（里面没有文字层，任何工具都读不出文字）。
如果打开后提示「没有解析出任何课程」，多半就是这个原因。

## 常见问题

**Q：导出的日历里时间是错的？**
改第 2 步的「每节课的时间」，重新生成即可。日历事件的时间完全按你填的作息生成。

**Q：不想一节节填时间？**
用「课间时间 · 自动安排上课时间」：填好每节时长、课间休息，再给上午 / 下午 / 晚上各填
开始时间和节数，点一下全排好。改完记得重新生成一次 `.ics`。

**Q：上午排到 12:10 才下课，下午又从 14:00 开始，中间这段怎么体现？**
那正是把上午 / 下午 / 晚上分开填的原因——午休是「下午时段的开始时间」决定的，
不是课间休息。三个时段各排各的，互不影响。

**Q：周次后面那个「不上：…」是什么？**
那是这门课**不上课的周**。周次范围里如果有跳过的周（单双周、国庆之类的假期），就在后面用浅色小字写出来，
例如 `3-16` 后面显示 `不上：8-9`，`1-19(单)` 后面显示 `不上：2-18(双)`。
如果每周都上（周次是连着的），后面就什么都不显示。它只是提示，不用你手动填。

**Q：想让上午、下午中间各空一个 20 分钟的大课间？**
在自动排课里把「大课间」填 `20`、「在第 `2` 节之后」。大课间在每个时段里各算一次，
所以上午第 2 节后、下午第 2 节后都会各空出 20 分钟。填 `0` 就取消大课间。

**Q：第一周日期填错了，日历会不会乱？**
会整体平移。改完日期后重新生成一份 `.ics` 导进去，把旧的那份删掉即可
（建议导入到同一个日历，方便整份删除）。

**Q：单双周的课上错了？**
周次那一栏写 `1-16(单)` 或 `1-16(双)`，或者点「选择」用「单周 / 双周」按钮点选。

**Q：同一门课不同周次在不同教室？**
在表格里加两行，课程名写一样，周次和教室分别填不同的值。

**Q：会重复导入吗？**
每个事件都有稳定的 ID，重复导入同一份文件时日历通常会识别为同一个事件。
换学期或改了作息后重新导出，建议先把上一份导入的日历整个删掉再导入。

**Q：数据会传到网上吗？**
不会。整个工具就是这一个 HTML 文件，PDF 解析、日历生成全部在你浏览器本地完成。
它也不主动请求网络。

## 开发者：重新构建

`课程表助手.html` 是由 `src/` 里的源码 + pdf.js + 字符集映射 + 示例 PDF 打包成的单文件。
要修改后重新生成：

```bash
cd build
npm install          # 只有 build/ 里需要依赖
node build.mjs       # 生成 ../课程表助手.html
```

目录说明：

```
课程表助手.html          最终交付物（单文件，双击即用）
课表.pdf                 内置示例课表
src/template.html        页面骨架
src/styles.css           样式
src/app.js               界面逻辑（打开 PDF、编辑、导出）
src/parser.js            PDF 文字 -> 课程结构化数据（纯 JS，无依赖）
src/ics.js               iCalendar(.ics) 生成（纯 JS，无依赖）
build/build.mjs          打包脚本（pdf.js 转经典脚本 + 内联 CMap + 示例 PDF）
build/parse-test.mjs     在 Node 里跑解析（对照 PDF 检查识别结果）
build/ics-test.mjs       在 Node 里检查 .ics 输出（行折叠、RFC5545 格式）
build/e2e.mjs            用无头 Edge + DevTools 协议做真实浏览器端到端测试
build/gen-compat.mjs     由 Unicode Unihan 数据生成 parser.js 里的兼容字符表
build/fixtures/          另外两种版式的测试 PDF
```

`build/` 整个目录只用于开发和测试，**删掉不影响 `课程表助手.html` 的使用**。
